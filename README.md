# Trace Lookup

A single-page OSINT search dashboard. Enter a name, phone number, email, street address, username, domain, or IP address and get:

- **Live checks** from free public APIs (GitHub, GitLab, Bluesky, Chess.com, Lichess, Hacker News, Keybase, Gravatar, DNS-over-HTTPS, RDAP, OpenStreetMap, ipinfo.io)
- **Pre-filled search links** to people-search sites (FastPeopleSearch, TruePeopleSearch, ThatsThem, USPhoneBook, Whitepages, etc.), social networks, public records, breach checkers, and Google searches

Everything runs in the browser. There's no backend and no build step. Open `index.html` or visit the GitHub Pages site.

## Responsible use

People-search data may not be used for employment, tenant screening, credit, or insurance decisions (US FCRA). Don't use this tool to stalk or harass anyone.
